# Wening UI

**Calm interfaces for serious applications.**

Wening UI is a reusable, information-first application design system and application-shell project for modern web products.

The project is currently in **Phase 0 — Product, Design & Agentic Governance Freeze**. Implementation code is intentionally deferred until the product principles, design language, repository governance, quality gates, and agent workflow are agreed and documented.

## Direction

Wening UI is being designed to support:

- admin and back-office applications;
- data-heavy workflows;
- focused operational screens such as check-in, gate, verification, and monitoring;
- public-facing product pages that share the same design language;
- light, dark, and system themes;
- reusable integration with Laravel/Livewire-oriented products, while keeping the design system conceptually framework-independent.

## Design character

Clear. Calm. Structured. Information-first. Accessible. Theme-native. Agent-ready.
